QUICK START (Windows + VS Code)

1. Open this folder in VS Code.
2. Open Terminal -> New Terminal.
3. Check Python:
   python --version
4. Install NumPy once:
   python -m pip install numpy
5. Run everything:
   powershell -ExecutionPolicy Bypass -File .\run_lab.ps1

The output will also be saved to results.txt.
Send results.txt back to ChatGPT so the tables and written answers can be completed from YOUR actual measurements.

- Task 4 can use a lot of RAM. Close heavy apps first.
